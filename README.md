## Sobre mí

Soy **ingeniero electrónico**, creativo y apasionado por aprender. Me adapto a nuevos retos y disfruto explorar tecnologías distintas para llevar mis ideas a la práctica.

Mis proyectos combinan **electrónica, desarrollo web y videojuegos**: desde conectar sensores y consultar sus datos hasta construir una interfaz o darle forma a un juego. Mi proyecto principal es **Parqueadero Inteligente UFPS**.

## Parqueadero Inteligente UFPS

Prototipo para contar entradas y salidas de motocicletas y consultar la ocupación del parqueadero de la Universidad Francisco de Paula Santander.

<a href="https://github.com/deyson24ivan/parqueadero-inteligente-ufps">

</a>

<sub>Dashboard del prototipo. Captura histórica conservada en la documentación del proyecto.</sub>

- **Detección:** sensores A/B y ESP32 para distinguir entradas de salidas.
- **Integración:** Raspberry Pi, MQTT/HTTP y PostgreSQL para recibir y conservar eventos.
- **Consulta:** dashboard Flask con ocupación, históricos y diagnóstico de nodos.

El montaje físico es un piloto de **un carril**; el mapa de **nueve carriles y 18 zonas** es una representación lógica.
